# `@repo/eslint-config`

Shared ESLint flat configurations for the YS Fitness workspace:

- `@repo/eslint-config/base` — repository-wide JavaScript and TypeScript rules
- `@repo/eslint-config/nest-js` — NestJS API conventions
- `@repo/eslint-config/next-js` — Next.js web conventions
- `@repo/eslint-config/react-internal` — rules for shared React packages
